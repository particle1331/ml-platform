# ml-platform

A local-first machine learning platform for a small team, built incrementally with MLflow, Celery, FastAPI, and Flet, with Azure and Terraform introduced after local behavior is understood.

- [Architecture and milestone specs](docs/specs/README.md)
- [Worksheet sequence and working method](docs/worksheets/README.md)
- [Start milestone 1: a local job system with a dashboard](docs/worksheets/milestone-01/README.md)

This repository currently contains specifications and a learning worksheet. Application code and tests will be written one module at a time. Each module ends with behavioral tests and a short explanation of what was learned.
